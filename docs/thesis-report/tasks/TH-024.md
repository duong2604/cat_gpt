## 7. Công việc chi tiết

1. Áp dụng HEP: backup bản cuối, cập nhật mọi field, kiểm tra lần cuối mục lục/danh mục.
2. Xuất PDF từ Word; kiểm font nhúng, số trang, hình rõ nét.
3. Lập gói bàn giao tại `exports\` (local):

| # | Sản phẩm | Định dạng | Ghi chú |
|---|---|---|---|
| 1 | Báo cáo đồ án bản cuối | `.docx` | `CAT_GPT_DATN.docx` |
| 2 | Báo cáo đồ án bản in/nộp | `.pdf` | Xuất từ Word |
| 3 | File nguồn sơ đồ | `.puml` / `.mmd` / `.drawio` | Toàn bộ sơ đồ trong báo cáo (Q12) |
| 4 | Ảnh xuất của sơ đồ | `.png` / `.svg` | Độ phân giải in được |
| 5 | Ảnh giao diện dùng trong báo cáo | `.png` / `.jpg` | Kèm danh sách SHA/ngày chụp |
| 6 | Dữ liệu và script thực nghiệm RAG | thư mục | Để tái lập 4.4 (không chứa khóa API) |
| 7 | Danh mục bàn giao + SHA-256 từng file | `.md` / `.txt` | |
| 8 | Thông tin phiên bản mã nguồn | `.md` | Repo, Report Baseline SHA |

4. Kiểm tra gói: mở được từng file, checksum khớp, không có secret.
5. Cập nhật progress, review-log, source-register (trạng thái cuối); ghi checksum vào báo cáo thực hiện.
