## 2. Mục đích

Tạo file Word chính thức duy nhất với style, đánh số, field và khung báo cáo đúng quy định; kiểm chứng công cụ tự động hóa Word và cơ chế Human Edit Protection trước khi bắt đầu soạn nội dung.

## 3. Phạm vi thực hiện

- Audit khả năng tự động hóa: Microsoft Word desktop có cài, phiên bản; COM qua PowerShell và/hoặc Python + pywin32.
- Tạo thư mục local `D:\workspace\CAT_GPT_Thesis\` với `references\`, `assets\`, `diagrams\`, `backups\`, `exports\`, `scripts\`.
- Tạo `CAT_GPT_DATN.docx`: khổ giấy, lề, số trang, style, đa cấp đánh số heading, caption, khung outline (chỉ heading, chưa có nội dung), mục lục và danh mục bảng/hình dạng field.
- Đối chiếu PDF quy định gốc (SRC-001) và chốt OPEN-004.
- Viết script hỗ trợ tối thiểu trong `scripts\` (local): kiểm trạng thái file/lock, backup có timestamp, xuất danh sách heading + hash, so sánh trước/sau.
- Kiểm thử Human Edit Protection.

## 4. Phạm vi không thực hiện

Viết nội dung báo cáo (kể cả bìa thật — TH-004); cài phần mềm không liên quan; mua bản quyền; đổi chính sách bảo mật/macro; thao tác cần quyền quản trị khi chưa được xác nhận; đưa file Word/script chứa đường dẫn cá nhân lên GitHub.

## 5. Điều kiện tiên quyết và phụ thuộc

TH-002 `APPROVED`; chỉ thị thực thi TH-003. Máy Windows có Microsoft Word bản quyền.

## 6. Nguồn đầu vào

SRC-001 (PDF gốc); [format-standard](../format-standard.md); [outline](../outline.md); [workflow mục 5](../workflow.md#5-human-edit-protection).

## 7. Công việc chi tiết

1. Kiểm tra Word: đường dẫn cài đặt, phiên bản, khả năng khởi tạo `Word.Application` qua COM (PowerShell; Python/pywin32 nếu đã có). Nếu chạy trong WSL: kiểm tra gọi được tiến trình Windows và đường dẫn `D:\`. Nếu COM không khả dụng → đề xuất phương án thay thế, dừng chờ quyết định.
2. Đọc PDF quy định gốc; đối chiếu từng mục ở [format-standard](../format-standard.md); ghi chênh lệch; đề xuất cách chốt các mục chưa xác định (đánh số trang phần đầu, bìa, caption, bảng, đoạn mã) để Project Owner duyệt.
3. Tạo cấu trúc thư mục local.
4. Tạo `CAT_GPT_DATN.docx`:
   - Page setup A4, lề 2,5/2,5/3/2 cm; số trang giữa, phía trên; các section cho phần đầu / thân / phụ lục.
   - Style Normal, Heading 1–3 đúng thông số; đa cấp "CHƯƠNG n" / n.x / n.x.y gắn với Heading; mỗi Heading 1 bắt đầu trang mới.
   - Caption "Hình" và "Bảng" có số chương; style caption theo quyết định bước 2.
   - Khung: bìa, bìa phụ (placeholder), lời cảm ơn, mục lục (TOC field), danh mục viết tắt, danh mục bảng, danh mục hình (Table of Figures field), Mở đầu, Chương 1–4 với toàn bộ heading trong outline, Kết luận, TLTK, Phụ lục.
5. Viết script local: kiểm lock `~$*.docx` và tiến trình Word đang mở file; backup timestamp; trích danh sách heading + đoạn văn + SHA-256 ra JSON; so sánh hai JSON.
6. Kiểm thử Human Edit Protection (trên bản sao thử nghiệm, không phải file chính thức):
   - a) file đang mở → script phát hiện và dừng;
   - b) sinh viên sửa thủ công một mục ngoài phạm vi → sau khi agent sửa mục khác, chỉnh sửa thủ công còn nguyên;
   - c) sửa thủ công trong phạm vi → phát hiện xung đột và dừng;
   - d) backup tạo đúng, file mở lại được.
7. Cập nhật field, xuất PDF thử vào `exports\` để kiểm bố cục; ghi hash file chính thức ban đầu.

## 8. Kết quả mong muốn

File Word chuẩn để mọi task sau chỉ việc điền nội dung vào đúng heading; quy trình sửa an toàn đã được chứng minh.
